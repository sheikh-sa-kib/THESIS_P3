# Outputs Documentation

## 1. File Inventory

Every experiment run produces the following files in `outputs/experiments/run_YYYYMMDD_HHMMSS/`.

### 1.1 Core CSVs

| File | Contents | Rows | Generated By |
|------|----------|------|-------------|
| `metrics_summary.csv` | Per-algorithm aggregate metrics | 1 header + N algorithms | `run_experiment.py:write_metrics_csv()` |
| `simulation_log.csv` | Per-step per-algorithm simulation state | 1 header + N steps × M algorithms | `run_experiment.py:write_step_csv()` |
| `routing_log.csv` | Offline benchmark results per algorithm | 1 header + M algorithms | `run_experiment.py` (inline in `main()`) |
| `algorithm_timing.csv` | Per-step reroute latency | 1 header + N steps × M algorithms | `run_experiment.py` (inline in `main()`) |
| `emergency_log.csv` | Steps with active emergencies | 1 header + variable | `run_experiment.py` (inline in `main()`) |

### 1.2 Metadata Files

| File | Contents | Generated By |
|------|----------|-------------|
| `environment.json` | System info, Python version, SUMO version, packages | `run_experiment.py:collect_environment()` |
| `network_metadata.json` | Edge count, junction count, source file | `run_experiment.py:get_network_metadata()` |
| `git_commit.txt` | HEAD commit hash (40 hex chars) | `run_experiment.py:get_git_commit()` |
| `config_snapshot.yaml` | Full experiment configuration (seeds, params, versions) | `run_experiment.py` (inline in `main()`) |

### 1.3 Route Files

| File | Contents | Generated By |
|------|----------|-------------|
| `{algorithm}.rou.xml` | SUMO route file for the algorithm's simulation | `run_experiment.py:generate_routes()` |

### 1.4 Plots (generated by `generate_all_plots.py`)

All plots are saved as both **PNG** (300 DPI, RGB) and **PDF** (vector, publication-quality) in `plots/png/` and `plots/pdf/`.

### 1.5 Processed Data (generated by `generate_all_plots.py`)

All processed datasets are in `plots/data/` as CSV files for reproducibility.

## 2. Metrics Definitions

### 2.1 Aggregate Metrics (`metrics_summary.csv`)

| Column | Type | Definition |
|--------|------|------------|
| `algorithm` | str | Algorithm name (dijkstra, astar, aco, bco, pso, e3hybrid) |
| `total_steps` | int | Number of simulation steps run |
| `total_vehicles` | int | Total vehicles inserted |
| `total_reroutes` | int | Successful reroute operations |
| `emergency_events` | int | Emergency events triggered |
| `max_congestion_edges` | int | Peak number of edges >80% occupancy |
| `max_blocked_edges` | int | Peak number of edges >95% occupancy |
| `avg_travel_time_s` | float | Mean travel time per vehicle (seconds) |
| `avg_speed_mps` | float | Mean traffic speed across all edges (m/s) |
| `throughput` | int | Completed trips |
| `completed_trips` | int | Vehicles that reached destination |
| `failed_trips` | int | Vehicles that failed to complete |
| `teleport_count` | int | Teleported vehicles (SUMO teleport) |
| `avg_rerouting_latency_ms` | float | Mean time per reroute computation (ms) |
| `total_execution_s` | float | Wall-clock time for this algorithm's simulation |
| `peak_memory_mb` | float | Peak process memory (MB) |

### 2.2 Step Metrics (`simulation_log.csv`)

| Column | Type | Definition |
|--------|------|------------|
| `algorithm` | str | Algorithm name |
| `step` | int | Simulation step (0-indexed) |
| `active_vehicles` | int | Vehicles currently in the network |
| `reroutes` | int | Cumulative reroutes so far |
| `emergency_events` | int | Cumulative emergency events so far |
| `blocked_edges` | int | Edges >95% occupancy this step |
| `congestion_edges` | int | Edges >80% occupancy this step |
| `avg_speed_mps` | float | Mean traffic speed this step (m/s) |
| `completed_trips` | int | Cumulative completed trips |
| `failed_trips` | int | Cumulative failed trips |
| `teleport_count` | int | Cumulative teleported vehicles |
| `travel_time_s` | float | Mean vehicle travel time this step (s) |
| `reroute_latency_ms` | float | Mean reroute latency this step (ms) |

### 2.3 Routing Benchmarks (`routing_log.csv`)

| Column | Type | Definition |
|--------|------|------------|
| `algorithm` | str | Algorithm name |
| `success_rate` | float | Fraction of successful routing requests |
| `avg_runtime_s` | float | Mean computation time per request (s) |
| `max_runtime_s` | float | Maximum computation time (s) |
| `min_runtime_s` | float | Minimum computation time (s) |
| `avg_distance_m` | float | Mean route distance (m) |
| `successes` | int | Number of successful routing requests |
| `failures` | int | Number of failed routing requests |
| `total_requests` | int | Total routing requests |

### 3.2 Figure Format

- **PNG**: 300 DPI, RGB, `bbox_inches='tight'`
- **PDF**: 300 DPI, vector, `pdf.fonttype=42` (editable text)
- **Font**: Serif (Computer Modern), 11pt base, 13pt titles, 12pt labels
- **Dimensions**: Bar charts 8×4.5 in, Line charts 9×4.5 in, Dashboards 14×10 in

### 3.3 How Regeneration Works

```bash
# Regenerate from latest experiment
python scripts/generate_all_plots.py

# Regenerate from specific experiment
python scripts/generate_all_plots.py -i outputs/experiments/run_20260709_104644

# Regenerate to custom output directory
python scripts/generate_all_plots.py -o my_thesis_figures

# List available experiments
python scripts/generate_all_plots.py --list
```

## 4. Processed Data Files

Generated by `generate_all_plots.py` in `plots/data/`:

| File | Purpose |
|------|---------|
| `summary_algorithm_comparison.csv` | All aggregate metrics in flat table |
| `summary_routing_benchmarks.csv` | All benchmark metrics in flat table |
| `summary_step_statistics.csv` | Per-algorithm min/max/mean of step data |
| `processed_metrics.csv` | Long-format (algorithm, metric, value) for plotting |

These allow full reproducibility — any plotting tool can recreate the figures from these CSVs.

## 6. Script Responsibility Map

| Task | Script | Function/Method |
|------|--------|-----------------|
| Run experiment | `scripts/run_experiment.py` | `main()` |
| Generate routes | `scripts/run_experiment.py` | `generate_routes()` |
| Collect environment | `scripts/run_experiment.py` | `collect_environment()` |
| Write metrics CSV | `scripts/run_experiment.py` | `write_metrics_csv()` |
| Write step CSV | `scripts/run_experiment.py` | `write_step_csv()` |
| Write routing CSV | `scripts/run_experiment.py` | inline in `main()` |
| Write timing CSV | `scripts/run_experiment.py` | inline in `main()` |
| Write emergency CSV | `scripts/run_experiment.py` | inline in `main()` |
| Write config snapshot | `scripts/run_experiment.py` | inline in `main()` |
| Write network metadata | `scripts/run_experiment.py` | `write_network_metadata()` |
| Write git commit | `scripts/run_experiment.py` | `get_git_commit()` |
| Generate all plots | `scripts/generate_all_plots.py` | all `fig_*()` functions |
| Write summary tables | `scripts/generate_all_plots.py` | `write_summary_table()` |
| Validation | `scripts/run_validation.py` | `main()` |

All post-processing is done by reading saved CSVs — no simulation rerun required.
